# Glossary

Domain shorthand used in the LebuserApp codebase and by Ruslan.

## Domain Terms
| Term | Meaning | Context |
|------|---------|---------|
| trasy | Routes | Delivery routes assigned to drivers |
| klienci | Clients | Stops/customers on a route |
| wózek | Trolley/cart | Equipment tracked per delivery (stays/returns/exchange) |
| dostawa | Delivery | A single delivery run |

## Schedule Codes
| Code | Meaning |
|------|---------|
| daily | Runs every day (Mon–Fri) |
| mwf | Mon / Wed / Fri route |
| tth | Tue / Thu route |
| other | Anything outside the above |

## Roles
| Term | Meaning |
|------|---------|
| admin | Can edit routes/clients, reorder, manage drivers |
| driver (kierowca) | Assigned to routes, decides trolley disposition on delivery |
