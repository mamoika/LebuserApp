## Provider Checklist

For each provider, record:

- provider name,
- service purpose,
- categories of data,
- region/data location,
- whether DPA/data processing terms are accepted,
- sub-processors link/export,
- transfer mechanism if outside EEA,
- admin accounts with access,
- 2FA status,
- backup/retention notes.
