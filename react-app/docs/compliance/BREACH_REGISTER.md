## Entry Rules

- Open a row within 24h of a suspected incident.
- Use a new ID in the form `BR-YYYY-NNNN`.
- If not reported to UODO, write a clear reason in `Risk assessment`.
- If reported, store the notification copy in controlled company storage and
  reference it in `Evidence reference`.
- Close only after corrective actions are complete or formally accepted.
